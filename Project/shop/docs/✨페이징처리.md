# 페이징 처리

## 페이징 처리 흐름
```
  사용자 요청
    ↓
/products?page=1&size=10
    ↓
Controller
    ↓
Pageable
    ↓
Service
    ↓
Repository / QueryDSL
    ↓
┌─────────────────────────────┐
│ ① 데이터 조회               │
│    OFFSET + LIMIT           │
│                             │
│ ② 전체 데이터 개수 조회     │
│    COUNT(*)                 │
└─────────────────────────────┘
    ↓
PageImpl<Product>
    ↓
Page<Product>
    ↓
Controller → View
```

## 주요 클래스 / 인터페이스
| 구분       | 이름                       | 역할                        |
| -------- | ------------------------ | ------------------------- |
| 인터페이스    | `Pageable`               | 페이징 조건을 전달                |
| 클래스      | `PageRequest`            | `Pageable` 객체 생성          |
| 인터페이스    | `Page<T>`                | 페이징된 결과를 표현               |
| 클래스      | `PageImpl<T>`            | `Page`의 대표적인 구현체          |
| 유틸리티     | `PageableExecutionUtils` | Count 쿼리를 최적화하여 `Page` 생성 |
| QueryDSL | `JPAQueryFactory`        | QueryDSL 쿼리 실행            |
| QueryDSL | `offset()`               | 시작 위치 지정                  |
| QueryDSL | `limit()`                | 조회 개수 지정                  |



### PageRequest
- 페이지 조건을 만드는 객체
- PageRequest.of() 페이지 조건을 지정하고 Pageable 객체 반환
```
PageRequest.of(0, 10);
// 1페이지, 10개씩
```
✨ 첫페이지는 0부터 시작!


### Pageable
- 페이지 정보를 Service, Repository 로 전달하기 위한 인터페이스
- 주요 메소드

| 메서드               | 의미            |         예 |
| ----------------- | ------------- | --------: |
| `getPageNumber()` | 현재 페이지 번호     |       `2` |
| `getPageSize()`   | 한 페이지의 데이터 개수 |      `10` |
| `getOffset()`     | 시작 위치         |      `20` |
| `getSort()`       | 정렬 정보         | `no DESC` |

### Page
- 현재 페이지의 데이터 + 페이징 정보 + 전체 데이터 정보가지고 있는 객체

| 메서드                     | 반환 타입      | 설명                     | 예시                  |
| ----------------------- | ---------- | ---------------------- | ------------------- |
| `getContent()`          | `List<T>`  | 현재 페이지의 데이터 목록         | `page.getContent()` |
| `getNumber()`           | `int`      | 현재 페이지 번호              | `0`                 |
| `getSize()`             | `int`      | 한 페이지에 보여줄 데이터 개수      | `10`                |
| `getNumberOfElements()` | `int`      | 현재 페이지에 실제로 들어온 데이터 개수 | `10`                |
| `getTotalElements()`    | `long`     | 전체 데이터 개수              | `153`               |
| `getTotalPages()`       | `int`      | 전체 페이지 수               | `16`                |
| `getSort()`             | `Sort`     | 정렬 정보                  | `no: DESC`          |
| `getPageable()`         | `Pageable` | 현재 페이지의 페이징 정보         | `PageRequest`       |
| `hasContent()`          | `boolean`  | 현재 페이지에 데이터가 있는지       | `true`              |
| `isEmpty()`             | `boolean`  | 현재 페이지가 비어 있는지         | `false`             |
| `isFirst()`             | `boolean`  | 첫 번째 페이지인지             | `true`              |
| `isLast()`              | `boolean`  | 마지막 페이지인지              | `false`             |
| `hasNext()`             | `boolean`  | 다음 페이지가 있는지            | `true`              |
| `hasPrevious()`         | `boolean`  | 이전 페이지가 있는지            | `false`             |
| `nextPageable()`        | `Pageable` | 다음 페이지의 페이징 정보         | `page=1`            |
| `previousPageable()`    | `Pageable` | 이전 페이지의 페이징 정보         | `page=0`            |



### QueryDSL 페이징 처리
- 페이징 처리 목록
```
  List<Product> content = queryFactory
            .selectFrom(product)
            .where(where)
            .orderBy(product.no.desc())
            .offset(pageable.getOffset())     // A  : 시작 위치
            .limit(pageable.getPageSize())    // B  : 개수
            .fetch();
```
```
  SELECT *
  FROM product
  WHERE ?
  ORDER BY no DESC
  LIMIT A, B
```

- 페이지 객체
```
new PageImpl<>(
            content,      // 데이터 목록
            pageable,     // page(현재 페이지), size(개수)
            total         // 전체 데이터 개수
    );
```


### 전체 구조
```
┌─────────────────────────────┐
│          Browser            │
│ /products?page=2&size=10    │
└──────────────┬──────────────┘
               ↓
┌─────────────────────────────┐
│ Controller                  │
│ Pageable pageable           │
└──────────────┬──────────────┘
               ↓
┌─────────────────────────────┐
│ Service                     │
│ search(pageable)            │
└──────────────┬──────────────┘
               ↓
┌─────────────────────────────┐
│ QueryDSL Repository         │
│                             │
│ offset()                    │
│ limit()                     │
│ fetch()                     │
│                             │
│ count()                     │
└──────────────┬──────────────┘
               ↓
        ┌──────────────┐
        │ PageImpl     │
        │              │
        │ content      │
        │ pageable     │
        │ total        │
        └──────┬───────┘
               ↓
        Page<Product>
               ↓
            View

```
