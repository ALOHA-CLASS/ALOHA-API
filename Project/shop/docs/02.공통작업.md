## 시큐리티 설정
### 인가 설정
1. 요청 대상 지정 메소드

| 메서드                 | 의미                    | 예시                          |
| ------------------- | --------------------- | --------------------------- |
| `requestMatchers()` | **특정 URL**을 지정        | `requestMatchers("/login")` |
| `anyRequest()`      | **앞에서 지정하지 않은 모든 요청** | `anyRequest()`              |

2. 접근 권한 지정 메소드

| 메서드                 | 의미                        | 예시                                    |
| ------------------- | ------------------------- | ------------------------------------- |
| `permitAll()`       | **모든 사용자 허용**             | `.permitAll()`                        |
| `authenticated()`   | **로그인한 사용자만 허용**          | `.authenticated()`                    |
| `hasRole()`         | **특정 역할 1개 필요**           | `.hasRole("ADMIN")`                   |
| `hasAnyRole()`      | **여러 역할 중 하나만 있으면 허용**    | `.hasAnyRole("ADMIN", "MANAGER")`     |
| `hasAuthority()`    | **특정 권한 1개 필요**           | `.hasAuthority("WRITE")`              |
| `hasAnyAuthority()` | **여러 권한 중 하나만 있으면 허용**    | `.hasAnyAuthority("WRITE", "DELETE")` |
| `denyAll()`         | **모든 사용자 거부**             | `.denyAll()`                          |
| `anonymous()`       | **로그인하지 않은 사용자만 허용**      | `.anonymous()`                        |
| `rememberMe()`      | **Remember-Me 인증 사용자 허용** | `.rememberMe()`                       |
