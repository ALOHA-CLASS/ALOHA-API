# 장바구니

## 장바구니 화면
1. 엔터티 정의
  - CartItem.java
  * N : 1 = CartItem : User
  * N : 1 = CartItem : Product

2. 레포지토리
  - CartItemRepository.java

3. 서비스
  - CartItemService.java
  - CartItemServiceImpl.java

4. 컨트롤러
  - CartController.java
  * /cart

5. 뷰
  - 상품 목록 화면
  - page/cart/list.html


## 장바구니 추가
1. 서비스
- userNo(회원번호), productNo(상품번호), quantity(수량)을 전달받아, cart_item 에 등록

2. 컨트롤러
- [POST] /cart      (비동기)    ➡ 처리된 장바구니 정보 응답
- [POST] /cart/add  (동기식)    ➡ 장바구니 내역(/cart) 리다이렉트
